# 12 — Web Portfolio

**A single-page personal portfolio showcasing operations and process design work, built to support a job hunt outside Screenwise.**

## Description

This is a hand-coded portfolio site (HTML, CSS, vanilla JS — no build step) designed to surface the internal tools and process-mapping work that don't naturally show up on a CV. It runs as a single `index.html` file with all styles inline, using only CDN dependencies (Inter font, Font Awesome, AOS for scroll animations) so it can be opened locally or deployed to GitHub Pages with no setup. The visual identity is intentionally lean and operations-focused rather than designer-glossy.

Three project cards are currently live — KPI Performance Calculator, Onboarding Flow Mapper, and Compliance Email Library — each linking out to the actual working tool inside this workspace. A fourth card for Line Test Support is staged as "Coming Soon" pending a screenshot. A fifth card is planned once the Comms Mapping project has a public-facing web tool. Supporting documentation lives in `PORTFOLIO_PLAN.md` (current state, card status, next steps) and `PUBLISHING.md` (deployment runbook for GitHub Pages, including the relative-path strategy for the linked tool folders).
